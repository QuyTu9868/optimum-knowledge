# Unverified claims

Things people repeat about Optimum that no source in this repo supports yet. Do not state them as fact. If you find a primary source, move the claim into the right file and remove it from here.

| Claim | Where it shows up | What's missing |

| RLNC patents are owned by MIT and licensed to Optimum | Community posts | Any patent number or license announcement |
| Optimum's RLNC library is "source-available, not open source" | Community posts | A repo, license file or official statement |
