# Unverified claims

Things people repeat about Optimum that no source in this repo supports yet. Do not state them as fact. If you find a primary source, move the claim into the right file and remove it from here.

| Claim | Where it shows up | What's missing |
|---|---|---|
| RLNC patents are owned by MIT and licensed to Optimum | Community posts | Any patent number or license announcement |
| Optimum's RLNC library is "source-available, not open source" | Community posts | A repo, license file or official statement |
| The MIT NEC chair passed from Nancy Lynch to Muriel Médard | Implied by Optimum's team page | An MIT source saying so |
| Seed round was $10M | Signalbase headline | The article itself; Optimum and The Defiant say $11M |
| 2026 IEEE Hamming Medal for Médard | Optimum team page | IEEE's own announcement |
| Blocks republished after a 30s TTL caused 30-46s latency spikes | Community posts | Any issue, PR, changelog or post. PR #121 adds a 30s dedup window but mentions no spike |
| Prysm is lenient and Teku/Lighthouse strict about the Gateway handshake | Community posts | Any source. PR #8 adds handshake gating with no client-specific notes |
| "Partial RLNC delivery" | Community posts | Any source |
| Mainnet propagation is "sub-200ms" | Community posts | Any source stating it. Still not in the launch blog or tweet; ~150 ms is a Hoodi testnet figure. The Hub's network-performance endpoint (2026-10-21) has a "spread" mump2p value of 133.7 ms, and the blog gives a 335 ms lead, which is a different metric |
| Up to 95% bandwidth reduction on mainnet | Community posts | A measured mainnet figure; the homepage gives 90-95% with no method or network, and the 2026-10-20 launch blog and tweet do not mention bandwidth |
| Discord copy of the launch announcement saying "$3.7B of Ethereum stake" and "2-3x" | Unlinked community repost | The tweet says $3.4B and 2-3x; the blog title says $3.4B, its body "over $3.7B" and "2.5 - 3.5x". No primary source has that exact mix. The repost is not a source |
| Mainnet is live with 16 or 20 operators | Launch blog says 16, homepage says 20 | A list of operators confirmed by the operators themselves; the Hub's front-end code lists names, which is not proof of participation |
| A dollar value for the Hub's ~1.419M ETH stake | Community posts | Optimum gives $3.4B and "over $3.7B"; no source says which ETH price or date |
| KuCoin research reported 2.42x / 7.88x | Community posts | The KuCoin piece found only has testnet numbers |
